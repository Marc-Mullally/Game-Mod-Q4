
----------
How to Install
----------

1. Download the "midterm_project" folder from GitHub (https://github.com/Marc-Mullally/Game-Mod-Q4/tree/midterm_project)
2. Insert the "midterm_project" folder into "Program Files (x86)\Steam\steamapps\common\Quake 4"
3. Done! To play the mod, open Quake 4, click "MODS", click "midterm_project", and then "Load Mod"

Refer to "How to Create Shortcut" to create a quick way to boot the mod. 

----------
How to Create Shortcut
----------

1. Right-click Quake4.exe
2. Click "Create shortcut"
3. Right-click the new "Quake4.exe - Shortcut" and left-click "Properties"
4. Insert "+set fs_game midterm_project" at the end of the "Target:" textbox
   (Do not delete what's already in the textbox, just put a space and insert the command after it)
5. Click "Apply"
6. Done! Double clicking or running the shortcut will automatically boot Quake 4 with the mod


----------
How to Play
----------
1. After spawning, open the console with CTRL + ALT + `
2. Insert "map game/convoy2"
3. You will be teleported to a new map, where you will have to kill the Hornet in front of you to start the game
4. Click H for a help menu

----------
How to Test
----------

Enemies constantly spawn:
After using "map game/convoy2", kill the Hornet and the enemies will begin to constantly spawn

10 different upgrades:
Use "giveupgrade " with an upgrade name to gain any upgrade you want

Loot from the enemies:
Kill an enemy that is spawning 

A boss that works with the waves:
Use "levelup 50" while in the arena to spawn in the boss
